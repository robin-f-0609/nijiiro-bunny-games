# 『さいごの、しろいページ』実装記録

実装日：2026-09-23。脚本：ユーザー提示の第8稿。共通仕様：IPB-COMMON 2.0。

## 採用した体験

- 51ページを一経路として読む（海2択×雨3択、全6経路）。54の固有ページID。
- クリーム色の紙と本文を中心にする。人物の立ち絵・顔・群衆を表示しない。
- 既存の5枚の風景は、新しい場所の発見、触る紙、旅の記録に使用。全面背景にはしない。
- 表紙を追加せずP01から開始。詩は第8稿の全文を採用。写真は地の文に留める。
- 本文は段落ごとに360ms間隔で表示。表示中のタップは全文表示だけ。全文表示から280ms、ページ遷移から380msは次の遷移を抑止し、連打による飛ばしを防ぐ。
- 選択を含むページは本文の表示完了後に選択できる。対象を押しても背後のページ送りには伝播しない。
- 紙を3枚拾う／守る、森を探る、雨音を重ねる、虹の紙を開く、思い出の4枚をめくる。
- 操作完了後も自動で進めない。紙はまとめて拾える／守れる。虹は1ボタンで開く。探索は飛ばせる。
- 誤答、採点、残機、時間切れはない。音は初期状態でオフ。SFXは控えめな合成音のみ。歌・自動音読・マイク入力は実装しない。
- 小型端末・文字拡大・横向きでは本文部分の縦スクロールを許す。ズームを禁止しない。
- 戻る、音切替、文字拡大、一括表示、動きを減らす環境、キーボード、画像読込失敗に対応。

## 脚本の絵・演出を本文へ置き換えた箇所

人物画像を省いても必要な出来事を伝えるための補足。筋書きや詩を変更しない。

| --- | --- |
| P02 | 三枚の紙が、ひらひら舞いました。 |
| P05 | 窓を「ロケットの丸い窓」と明示。 |
| P13 | 「うみ」と書き直すと、消しあとが少し残りました。 |
| P31 | 広場には、すすきと、うさぎの形のおまんじゅう。人間たちが、おだんごのお皿を持って、笑顔でこちらへ歩いてきます。 |

「あまやどりのさんにん」は本文に描かれた内容と文字の記録で表現し、人物画は制作しない。「しょんぼりしたぼうし」はCSSの簡単な小物図形で表現。海の紙と雨の記録は同じ紙の絵と余白として表し、後半でも海の文字はにじんだまま。海の最初の呼び名は別の状態として覚える。

## 状態と再開

`localStorage` の `nijiiro:fujita-white-page:v1` に版・現在のページID・海の選択・雨の選択・拾った紙・守った紙・虹を開いた状態を保存。外部送信しない。ブラウザのデータ削除まで保存される。保存できない環境では同じタブのメモリ上で遊べる。

- 「もどる」は状態を維持する。過去の選択肢は再びすべて選べる。
- 選び直すと、分岐ページ、P13、P39、P41、記録の絵を選択値から再計算。無関係な選択や操作完了は保つ。
- メーターはページの値から導出。再表示・連打で加算しない。P42は常にひとりぶん。
- 「もういちど よむ」は物語状態を初期化する。文字設定は保つ。音は再訪問時にオフ。
- 保存版・ページ・選択値は検証し、不明な保存データで途中の選択を飛ばさない。

## ファイルと運用

- `fujita-earth-trip/story.js`：全本文、台詞、分岐、各ページの演出指定。
- `fujita-earth-trip/app.js`：読書エンジン、状態管理、操作、音。
- `fujita-earth-trip/style.css`：紙面と表示。
- `fujita-earth-trip/assets/`：WebPで最適化した採用画像8点。
- `index.html`：作品が増えたときにも入口になる本棚。
- `nijiiro-rescue/index.html`：以前の終了希望に従いゲーム本体を取り除き、本棚へ案内。旧ソースはGit履歴に残る。
- 公式サイトのリポジトリ・Cloudflare設定は変更対象外。
- 相対URLだけで動作し、GitHub Pagesのプロジェクト配下でも使える。ビルド処理・外部CDN・有料サービス・アカウント登録は不要。

確認はローカルHTTPサーバー上で行う。例：`python -m http.server 4173` をリポジトリ直下で実行し、`http://localhost:4173/fujita-earth-trip/` を開く。

DOMによる機能検証は `npm install` の後 `npm run test:dom`。ブラウザーの経路テストは `npx playwright install chromium` の後 `npm test`。HTTPサーバーを起動しておくこと。`TEST_URL` と `TEST_ARTIFACTS` で対象URLと検証画像の出力先を変更可能。GitHub Actionsでブラウザー検証も完了し、全6経路が合格した。

`scripts/build-offline.py` で画像・コードを内蔵した試遊用HTMLを生成できる。試遊版では本棚も同じファイル内に含め、ネット接続なしで戻れるようにしている。
