# 検証結果

2026-09-23。確認対象：第8稿／IPB-COMMON 2.0の実装。

## 実施した確認

実際のDOM要素とクリックイベントをHappy DOMで生成し、`story.js` と `app.js` を一緒に実行した。これはブラウザーの描画確認ではない。

- 全6経路（うみ／おふろ × 雨つぶ／帽子／三人）：いずれも51ページでP51へ到達。
- 紙の個別タップとまとめて拾う操作：いずれも3枚揃い、手動の「つぎへ」を待つ。
- 森・雨の視覚反応、虹の観音開きと代替ボタン。
- 海の呼び名によるP13の訂正、P39の思い出、P41の雨の選択の再表示。
- 戻って選択変更した際に後半が新しい選択を参照する。
- 本文表示中のタップが全文表示に留まり、連打で未読ページを飛ばさない。
- メーターが戻る・再訪問・再読み込みで増殖しない。P42は常にひとりぶん。
- 途中再開、拾い済みの紙の保持、再読時の初期化。
- 不正な保存版・欠けた選択・保存不能時の扱い。
- 画像読込失敗時の代替説明と、その後の選択進行。
- 本文・エンジン・試遊版JavaScriptの構文検査。

`tests/dom-results.json` に実行結果を保存。`npm run test:dom` で再実行できる。
